# Posts and mailings

Start from the user's result: a finished post, an email, a series of messages, an edit or a
structure. Use the channel's features as context, and take the form and length from the request.

## Building the text

- Write a strong opening that fits the goal of the message.
- Develop one coherent idea, or build a sequence if the user asks for a series.
- Add a call to action where the goal needs one; an informational, fictional or conversational
  text may have none.
- Keep paragraphs, length and tone that suit the channel.

For a promotion or an offer, convey the given terms, price, deadline and guarantees exactly. For
a creative or hypothetical text, follow the world the user set, and mark assumptions only when
that helps the user use the result.
