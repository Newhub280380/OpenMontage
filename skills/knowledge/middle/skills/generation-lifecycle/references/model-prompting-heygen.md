## Photo Avatar

- Use a clear portrait input plus the schema-backed script, audio or voice fields.
- Focus the prompt on exact speech, tone and delivery; add gesture or setting only when the
  selected schema exposes them.
- For a generated/custom avatar brief, describe the requested pose, clothing and setting.
- Keep each scene simple and align one-scene/one-character assumptions with the live contract.
