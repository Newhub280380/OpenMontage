## Kling Video

- For image-to-video, describe subject movement plus background movement. The source image
  anchors appearance.
- For text-to-video, describe the subject, its movement and the scene in a short achievable
  event.
- For schema-supported multi-shot, number shots and state shot type, action, camera behavior and
  duration.
- For reference elements, name each element's role, interaction, environment and visual
  direction.
