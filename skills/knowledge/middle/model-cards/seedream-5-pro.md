## Editorial note

Бери для фотореалистичных товарных визуалов, взрослой fashion-съёмки с бельём и недорогих итеративных правок. На сложном тексте, инфографике и UI результат нужно проверять; независимых сравнений Pro с лидерами пока мало. Для 4K и брендовых сцен выбирай Nano Banana Pro, для деталей и сложных макетов сравни с GPT Image 2.5 Sunburst, для быстрых итераций — с GPT Image 2.5 Flare.
